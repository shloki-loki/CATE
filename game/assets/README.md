# `game/assets/` — source assets

Inputs for the asset generators in `tools/`: generator parameters, palettes,
hand-written data (for example vehicle specs used to build `.glb` models).
Nothing here is loaded by the browser directly.

- **Built output** goes to `public/assets/` (served as-is) and is listed in
  `public/assets/manifest.json`. Game code asks for assets by id through
  `src/assets` (`assets.url('vehicle.sports01')`), never by raw path.
- **Everything must be original.** Generated by our own scripts or hand-written
  here. No ripped or third-party game assets, and no trademarked names
  (architecture T0016 §0). T0018 defines the full pipeline and naming rules.
- Conventions: 1 unit = 1 metre, +Y up, models face +Z, ids are lowercase dotted
  (`category.name##`).
